# 推荐排序、评估与版本切换

推荐追踪把“策略是否成立”“候选研究优先级”“现在能否执行”分别处理。当前默认采用 `qr2` 质量规则；AI 在真实候选与冻结证据内分析、精选并说明风险。量化分、AI 置信度和证据完整度都不表示已校准的获利概率。

基础优化见 [推荐模块优化清单](RECOMMENDATION_OPTIMIZATION_PLAN.md)，本次价格、策略和通知复核见 [逐项验收记录](PRICE_STRATEGY_NOTIFICATION_REVIEW.md)。程序回归可以验证规则和数据口径，实际准确率与收益改善仍需成熟的真实样本验证。

## 推荐流程

```mermaid
flowchart LR
    A[发现 / 自选 / 策略信号 / 榜单] --> B[全部策略命中先做本地预选]
    B --> C[按来源分配入池与评分预算]
    C --> D[完整日线、策略条件与报价核验]
    D --> E[策略相关评分与入场质量]
    E --> P[共同价格计划与费用后风险收益]
    P --> F[行业 / 相关性约束]
    F --> G[最多 10 只候选供 AI 分析]
    G --> H[用最新报价复核执行条件]
    H --> I[冻结事实、追加追踪与成熟结果]
    I --> J[只读研究与时间外对照]
```

- 精细入池最多 240 只，首轮评分名额最多 48 个；排除后按冻结的来源预算次序补评一轮。最终推荐仍为 3～5 只，AI 输入最多 10 只。
- 显式选股策略先对全部命中做本地因子预选，再按策略信号预算截断。普通选股页继续按成交额展示，不因推荐排序改动而改变原契约。
- 来源预算为自选、发现、策略信号与榜单轮转分配；优先来源只占有界预留名额。完整观察池记录超预算、未评分、条件不满足与数据不足的原因。
- 显式选股条件是必要条件，混合来源也须满足。条件使用“满足、不满足、未知”三值逻辑；缺字段不能当作条件为否，OR 分支保留原语义。
- 指标形态只使用已完成日线。收盘突破、收盘量能与现价至均线的距离分别保存；盘中报价不拼造成一根历史日线。

## 评分方式

### 策略侧重

| 配置 | 重点 |
| --- | --- |
| `balanced` | 技术、波动和入场距离的均衡研究 |
| `momentum` | 趋势突破、突破前整理与突破后的承接 |
| `pullback` | 趋势内回踩、缩量和低点/收盘企稳 |
| `active` | 量价承接、活跃换手和拥挤风险 |
| `value` | 估值与盈利能力互相支持，避免把亏损低价当作低估 |
| `growth` | 营收与利润增长、盈利质量和趋势配合 |
| `leader` | 盈利稳定性与规模参照，市值不能直接证明行业地位 |

26 个内置选股策略和 4 个模板显式声明侧重与形态意图。自建策略可以独立选择侧重，并随不可变策略 revision 保存；旧策略未指定时，新生成使用均衡技术配置。持有周期仍决定执行与评估窗口，不再代替策略意图。

新增的常用策略均可在选股页及推荐生成时使用：

| 策略 | 条件重点 |
| --- | --- |
| 20/60 日均线金叉 | 近 3 日上穿且当前仍保持，收盘站上两条均线 |
| 放量突破后回踩确认 | 先有量突破，2～10 日后回踩原平台并企稳；中途失守则不成立 |
| 布林收口后放量突破 | 前一日带宽位于历史低位，再放量突破当时已知上轨 |
| 55 日价格通道突破 | 收盘严格超过此前 55 日最高价，配合量能和收盘位置 |
| KDJ 低位金叉修复 | 前日 K/D 均低于 30，最新日上穿且收盘上涨，并处于 60 日区间下半部 |

这些是候选条件，实际推荐还要通过流动性、形态完整性、延伸距离、入场和风险检查。未以新增策略数量推断收益改善，也未用缺乏完整现金流、估值或指数成分历史的数据拼造“高胜率”财务策略。

### 质量规则 `qr2`

技术基础之外，分别计算形态质量、入场质量、交易风险、财务质量和信息背景。每组限制贡献，不再对已有技术维度之外的 RSI、MACD、均线多头和创高等相关信号反复加分。核心技术可用权重不足 60%，或缺少信号前 ATR 时，不参与新评分。

突破质量使用信号日之前的 ATR、整理振幅与成交量、收盘承接、上影线和趋势效率。连续创高以本段突破起点及起点前 ATR 为参照，最多回看 10 日，避免每天重置或上涨后 ATR 扩大掩盖连续延伸。ATR 距离按波动归一，保留合理的强势突破机会；评分调整不等于简单压低所有涨幅。

价值等财务型策略要求估值与年度盈利质量、近期营收或净利润同比共同支持。`ff1` 使用最新已披露报告的同比和最近已披露年报的加权 ROE；不能把季度累计 ROE 直接比较年度阈值或简单乘倍数年化。两份报告在补拉规划前一起冻结，缺字段和真实零值明确区分；所需财务字段不全时，只作研究观察，执行检查保持依据不足。同行估值分位仅在本批至少有 5 个可用同行时计算，并记录样本量；它是本批候选的相对参照，不是全行业估值排名。缺失财报明确记录，不补造成中性财务事实。

`entry_quality` 分为距离合理、延伸较大、等待确认、依据不足。后三类可继续作为研究对象，但程序执行计划保持等待或不可用。AI 完成后重新取得行情，核对价格区间、累计涨幅、现价约束与入场质量；不能仅因 AI 输出 buy 就把旧报价标为 fresh。模型原始动作与程序执行结果分别保留。

### 完整排序值与对照

`ranking_score` 保存六位小数，允许零、负值和超过 100 的值；非法数值不能排序。`score` 为限制在 0～100 的展示值。初排、富化优先级、终选、送模顺序和量化降级使用同一排序约定。

| 版本 | 含义与生效方式 |
| --- | --- |
| `qr2` | 当前默认质量规则，按分组形成总排序值 |
| `additive_sp1` | 同一机会集、同一策略侧重下的原加法评分；可用于评分消融与显式回退 |
| `ridge1` | 使用已保存且满足启用条件的正则线性模型；默认不启用 |

加法对照沿用当前候选预算、条件核验和执行检查，**不代表旧版全流程重放**。质量规则分解始终表示 `qr2`，采用其他版本时不能将分解总和解释为生效排序值。

学习模型从训练段拟合均值、尺度、缺失指示和中心化参数，使用 16 个技术/质量/财务特征。常量和全缺失特征失活，正则系数仅在验证段从 1、10、100 中选择；训练目标固定裁到 ±50%，测试收益保留原值。线上排序使用 `50 + 线性输出` 的固定平移，保持模型相对次序，只用于现有分数展示，不作收益预测或概率解释。

## 共同买卖价

`rp1` 以报价时点已完成的尾部最多 120 根日线、策略和周期生成买入观察区间，退出复用 `xp1` 的支撑阻力、ATR 止损与分阶段目标。按买入上沿计算扣费后的第一目标收益/风险；不足 1.2R 时尝试降低买入上沿，仍不足则等待，不能抬目标凑比例。

个股分析可以选择相同策略和周期；从推荐卡发起复核会自动传递二者。两页显示相同程序计划，原始 AI 价位单独标为未生效。共同计划回填既有买卖价字段，提醒与追踪继续读取它们；AI 分析耗时后的新报价只用于执行复核，不追抬冻结价位。历史结果不重算，实际持仓保护另考虑成交成本、公司行动与持仓阶段。

价格计划不改变既有评估的含义：`next_open` 是次日开盘成交模拟，不是严格在买入观察区间内才成交；触及目标也不代表用户已实际买卖。

## 只读评估

管理员打开“选股配对评估”中的“推荐排序研究与版本”，选择样本来源、侧重、5/10/20/60 日持有期及扣费/超额目标，再主动运行。页面保留失败前的结果，并明确显示该结果自己的请求参数、截止日、覆盖和数据摘要。

| 来源 | 读取内容与边界 |
| --- | --- |
| `recommendations` | 最近 1000 个事实完整批次的全部合格评分候选；要求 `of2` 快照、摘要、身份、版本和分组可核验。重复或损坏事实使该批机会集整体排除 |
| `snapshots` | 当日股票宇宙与 `fv7` 因子快照；以窗口内首个当时可知宇宙为固定群组，按代码哈希选取有界子样本；后上市股票不加入该群组。每个日期使用当日存续/ST/停牌状态；晚于当日入库、旧特征或缺失字段不能补造 |

历史快照直接保存 `sq2` 质量特征与技术维度。旧 `fv1`～`fv6` 数据不能事后升级成完整新样本；今天重锚后的日线只计算结果，不重建旧输入特征。历史财务单字段的零值不能区分真实零与未提供，学习时保守当作缺失；ff1 的已知零值可参与学习，ROE 特征明确为 `annual_roe`。读取 fv7 还要求 `verified_adjustment` 质量标记，并报告财务覆盖。

评估复用 `so3` 固定持有执行器：下一交易日开盘尝试成交，按同一费用、涨跌停、停牌、T+1 与延迟退出规则结算；计划障碍标签为 `l4`。沪深主板风险警示股票在 2026-07-06 前按 5%、此后按 10%，入场和每个卖出日分别判定，科创板买入至少 200 股。旧 so2/l3 终态保留但不混入当前口径，未完成标签按当前执行器结算后记录实际版本。当前版本的已保存结果可以补足日线保留期；不把带止盈止损的计划标签混入纯选股比较。指数基准来自独立已收盘缓存，研究入口不触发外部补拉。

交易规则依据：[深交所 2026 年修订通知及附件](https://www.szse.cn/lawrules/rule/trade/current/t20260424_620190.html)、[上交所 2026 年修订规则及暂缓条款](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。名称/板块回退仍是近似；有有效实际涨跌停报价时优先使用报价，历史计算仍依赖当时的股票身份与价格口径。


- 先排序选 TopK，再检查未来成交和收益；不能根据未来可成交性补选下一只。
- 真实未成交的拨款持有现金，观察到同一持有期结束；相对基准的机会成本仍计入超额收益。缺日线、未成熟和强制退出分别计数，不能当作零收益。
- 按交易日期滚动划分训练、验证、测试，间隔包括持有期 purge 与 5 日 embargo；实际延迟退出跨界的标签仍须排除。测试结果不参与选参和拟合。
- 每个信号日期的训练总权重相同，多个批次不能伪造更多独立市场样本。重叠测试记录只保留最近一次合法模型预测。
- 有学习测试预测时，三种算法汇总限制到同一测试机会集；尚不能拟合模型时仍展示规则的独立测试对照。
- 结果按信号日期等权汇总，区间使用长度为“持有期 + 1”的日期块重采样，不将重叠持仓的收益复利成年化结果。描述统计包含训练期，不能作为时间外收益增益证据。

### 独立 CLI

从 `server/` 执行，显式传入现有 SQLite 文件：

```bash
go run ./cmd/recommendation-eval -sqlite /absolute/path/research.sqlite -source recommendations -type short_term -profile momentum -horizon 10 -target alpha
```

Windows 示例：

```powershell
go run ./cmd/recommendation-eval -sqlite 'D:\Research\input.sqlite' -source snapshots -profile pullback -horizon 5 -max-dates 240 -max-symbols 100
```

CLI 强制使用 `mode=ro` 与 `query_only`，不读取 `.env`、不执行应用初始化或迁移、不启动调度、不调用行情与 AI。输出为 UTF-8 JSON。不存在的路径会报错，不能创建空库充当输入。数据库若在写入，应使用与 WAL 一致的备份或 SQLite 正式备份，避免只复制主文件遗漏数据。

短线持有期支持 5/10 日，长线支持 20/60 日。可选参数：`-as-of YYYY-MM-DD`、`-max-dates 120..1080`、`-max-symbols 10..500`、`-top-k 1..10`。历史快照单次最多 12 万个股日，默认 480 日 × 200 只；同日未收盘时截止日向前取完整日期。管理员 HTTP 接口为 `GET /api/admin/ranking-research`，与 CLI 共用研究引擎。

## 保存、启用与回退

1. 运行研究后，只有最近一折有合法模型时才能“保存本次研究模型”。服务端重算并比对数据摘要，不接受客户端上传的系数、收益或通过标记。
2. 保存生成不可变工件 `ra1`，包含模型、预处理参数、时间切分、样本摘要与报告。保存不会改变推荐采用的算法。
3. 只有真实推荐机会集符合时间外门槛的模型才能启用：至少 100 笔时间外成交、足够完整日期和配对日期；主目标相对两种规则的增量区间高于零；另一个收益口径不得恶化；结果和基准覆盖至少 95%、可成交率至少 80%；尾部风险与财务覆盖同时通过检查。历史收盘快照只能作研究。
4. 在相同推荐周期与评分侧重下选择模型并“应用评分版本”。版本切换通过修订号比较防止旧页面覆盖新设置，成功变更追加审计。
5. 回退时明确选择质量规则或原加法对照并应用。只影响后续提交，已接受任务继续使用原模型与条件，不混用两种排序版本。

API：`GET /api/admin/ranking-policy`、`POST /api/admin/ranking-artifacts`、`PUT /api/admin/ranking-policy`。只有管理员可访问；这些写操作分别只保存研究工件或更新评分政策，不修改行情、历史推荐、成熟标签或交易账本。

本次报告版本为 `rr2`，规则为 qr2；旧 qr1 政策在新请求中使用 qr2 并冻结实际版本，旧学习工件必须按新特征重新研究验证。

推荐作业请求版本为 4。完整策略定义、条件树和评分模型保存在批次 `runtime_snapshot`，JobRun 只保存运行摘要及规范化请求；避免复杂条件撑破 16 KiB 任务快照，也避免复制模型与策略正文到任务中心。重启和显式重试均核对原批次摘要。缺少完整算法快照，或冻结的策略/特征版本已不受支持的未完成作业（也包括旧算法 v4 作业），会明确失败并提示重新生成，不能悄悄改用新算法；已完成历史仍可读取。

当前没有足够本地真实推荐样本证明收益提高，不会自动生成或启用一个“已验证”模型。满足数值门槛也不保证未来结果；持续评估仍需同时观察 AI 与纯量化、score-blind 实验、策略分层、覆盖率、严重亏损和组合暴露。
